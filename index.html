Tópico 1

Tipos novos e Operadores

Antes dos operadores, dois tipos novos que vão aparecer bastante hoje:

boolean

Guarda só dois valores possíveis: true (verdadeiro) ou false (falso). É o resultado de toda pergunta que o código faz.

boolean ligado = true;

char

Guarda um único caractere, entre aspas simples.

char letra = 'A';

Operadores Aritméticos

Os mesmos da matemática, com um convidado surpresa: o resto da divisão.

Tópico 2

Estruturas Condicionais

É aqui que o programa começa a "pensar". Com if, um bloco de código só roda se uma condição for verdadeira.

Idade.java
int idade = 20;

if (idade >= 18) {
  System.out.println("Maior de idade");
} else {
  System.out.println("Menor de idade");
}

Quando existem mais de duas possibilidades, usamos else if encadeado:

Nota.java
double nota = 7.5;

if (nota >= 9) {
  System.out.println("Excelente");
} else if (nota >= 7) {
  System.out.println("Bom");
} else if (nota >= 5) {
  System.out.println("Regular");
} else {
  System.out.println("Precisa estudar mais");
}
Ordem importa! O Java testa de cima para baixo e para no primeiro if/else if verdadeiro. Por isso a ordem das comparações muda o resultado.

Tópico 3

Entrada de Dados com Scanner

Até agora, os valores das variáveis eram fixos no código. A classe Scanner permite que o usuário digite um valor enquanto o programa está rodando.

Entrada.java
import java.util.Scanner;

Scanner teclado = new Scanner(System.in);

System.out.println("Digite seu nome:");
String nome = teclado.nextLine();

System.out.println("Digite sua idade:");
int idade = teclado.nextInt();

System.out.println("Olá, " + nome + "! Você tem " + idade + " anos.");

Um método para cada tipo

MétodoLê um...
nextLine()String (uma linha inteira)
nextInt()int
nextDouble()double
Cuidado clássico: se você chamar nextInt() logo depois de nextLine() (ou vice-versa) sem entender a ordem, o programa pode "engolir" uma linha e parecer que travou. Por hoje, o importante é: cada método lê um tipo, na ordem em que o usuário digita.

Tópico 4

Laços de Repetição

Laços repetem um bloco de código várias vezes, sem precisar copiar e colar linha por linha.

for — quando eu sei quantas vezes repetir

Contador.java
for (int i = 1; i <= 5; i++) {
  System.out.println("Contando: " + i);
}

Três partes separadas por ponto e vírgula: início → condição → o que muda a cada volta.

while — quando eu repito até algo acontecer

Senha.java
int tentativas = 0;

while (tentativas < 3) {
  System.out.println("Tentativa " + tentativas);
  tentativas = tentativas + 1;
}
Loop infinito: se a condição do while nunca virar falsa, o programa repete para sempre. Sempre confira se existe algo dentro do laço que muda a condição.
